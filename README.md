# Nexora

A game engine written from scratch. C++23, CMake, Conan.

Architecture and design decisions are based on Unreal Engine, simplified.

## Requirements

CMake 3.25+, Conan 2, MSVC (C++23), clang-format.

## Build

```bat
Automation\build_debug.bat
Automation\build_release.bat
```

Other scripts: `generate_project_files.bat`, `clean.bat`, `format_all_files.bat`.
